# My Family

تطبيق Android خاص للأسرة لمتابعة الدراسة، الصلوات، حفظ القرآن، المصروفات، التواجد، الزيارات، المهام، الصحة، والتواصل العائلي.

## التقنية

- React Native + Expo SDK 57
- TypeScript
- Supabase (يُربط في المرحلة التالية)

## التشغيل محليًا

```bash
npm install
npm start
```

## الصلاحيات

- جاسم: مدير النظام الوحيد.
- باقي أفراد الأسرة: مستخدمون عاديون، لا يطّلع كل منهم إلا على البيانات التي تسمح بها سياسات النظام.

## الحالة الحالية

- هوية التطبيق العربية.
- تسجيل دخول حقيقي عبر Supabase مع حفظ الجلسة بأمان على الجهاز.
- ربط حساب جاسم بصفة مدير الأسرة الوحيد.
- لوحة المدير والأقسام الرئيسية.
- قائمة أفراد الأسرة وأدوارهم في `src/data/family.ts`.
- قاعدة الأسرة والأعضاء العشرة وسياسات RLS.
- إعداد EAS لبناء APK داخلي قابل للتثبيت.

## نقطة الاستكمال

تسجيل الدخول إلى Expo CLI ثم تشغيل بناء Android باستخدام ملف `eas.json` والملف الشخصي `preview`.
